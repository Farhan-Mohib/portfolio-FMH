Project 01 Best Paper Award Peer-reviewed

SAM-Augmented Blending for Enhanced Microplastic Detection Using YOLO11

Novel synthetic data augmentation framework addressing the scarcity of annotated underwater imagery. Leveraged the Segment Anything Model (SAM) for automated mask generation, then built intelligent synthetic datasets through blending and copy-paste augmentation. Trained YOLOv11 on the augmented data and measured detection gains directly against baseline.

Mavirov Leviathan — Underwater ROV

Architected the full software ecosystem for Mavirov's first underwater drone. Hierarchical control across a Pixhawk autopilot and a Raspberry Pi 5 hub managing real-time video, telemetry and servo coordination. PS5-joystick and keyboard control with fine-grain servo trims.

MATE ROV 2026 · Competition Operations Software

MIST Mavirov ROV Ground Control Station

Designed and developed a unified desktop ground-control application for operating and supervising the competition ROV. The application brings vehicle telemetry, flight-mode control, multi-camera viewing, manipulator control, mission planning, sensor analysis, vehicle configuration and safety monitoring into one pilot-focused interface.

Integrated architecture: the GCS coordinates MAVLink telemetry from the Pixhawk/ArduSub stack, RTSP camera streams from the Raspberry Pi, and a separate UDP link to the Teensy manipulator controller over the same tethered Ethernet network.
